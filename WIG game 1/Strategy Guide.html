01游戏概览与操作入门

《星都双子1》是一款运行在浏览器中的悬疑解谜游戏。在拟物化的「星都OS 2066」桌面系统中，你会用邮箱、星搜、网盘、远程桌面、加密频道、暗涌论坛与政务内网，一层层揭开真相。这一部里，幕后资本巨兽「辰天集团」的影子贯穿始终——从网盘的离职证明，到政务文件上的统筹办公室，它正一点点浮出水面。

基本操作

  • 单击桌面图标打开应用；窗口可拖动、最小化、关闭。所有搜索关键词均有对应页面，不会再有「该页面不存在」的死胡同。
  • 星搜（公共信息网）会记录最近搜索，主页可点击历史关键词一键重搜。
  • 左下角胶囊显示当前任务目标；点击打开任务窗口，关键节点出现红色抉择按钮。
  • 页面所有文字均可选中复制（邮件、聊天、档案）。
  • 超过 50 秒没有操作，右下角弹出「闪念」提示，按当前进度给出方向——卡住时等一等也是一种攻略。
  • 进度保存在页面内存中，刷新会从头开始；搜索与开应用约半秒到一秒加载延迟，是刻意模拟的系统响应。

04三个结局指引

第五章的三个选项对应三个结局。

结局一 · 真相的重量

选择：发布报道。报道在十分钟内引爆全网。特警突入临港东郊 3 号仓库地下，救出林北辰的父母和十七名即将被「转运」的冗余体。小林B 因「证据不足」未被当场处置，但被列为「高度关注对象」，从此活在镜头之下。新闻插播中辰天集团股价盘中暴跌，随即声明系「个别底层员工的违规操作」、开除替罪羊——断尾求生，为续作伏笔。一周后小林A 来信问：「沈记者，我弟弟……算是活下来了吗？」而你桌上放着辰天集团法务部寄来的律师函——以「侵犯商业机密」和「严重损害企业名誉」为由起诉你。

「真相是有重量的。它压垮了一些人，也压在一些人的名字上，永不风化。」

结局二 · 枪声过后

选择：现场营救。你没有发布报道，根据小林B 的指引远程入侵 3 号仓库监控，关闭警报、指引路线。监控屏幕里，那个眼神冰冷的少年在货架间穿行，像一台精密的机器。他找到了林母——就在他要带她离开的时候，保安的手电光扫了过来。他把她推进暗处，自己迎了上去。一声枪响。屏幕一片雪花，你疯狂呼叫他的频道，没有回应。十分钟后新闻弹出：「临港市东郊发生一起恶性暴力事件，一名身份不明的青少年被击毙。」三天后你收到匿名快递，一个贴着「B」的U盘，只有一个文件：「谢谢你，至少我努力过了。」你的报道，永远没有发出去。

「他这一生只被爱过一次，还是他自己偷偷给的。」

结局三 · 幸存者的愧疚

选择：删除一切证据。你彻底删除所有关于「双子计划」的帖子，格式化U盘，销毁录音，给小林A 发去最后一条消息：「忘了这一切吧。好好活下去。」小林A 通过成人礼测试，和「归来的」父母继续生活，考上大学，毕业后成为一名公务员。档案科那份涂黑的记录再没有人翻开过。多年后，你凭一篇城市绿化报道获得「星都优秀记者奖」，颁奖典礼上小林A 作为优秀青年代表为你颁奖。握手的那一刻他看着你的眼睛轻声说：「我梦到他了。他说他原谅我了。」你的笑容僵在脸上，手中的奖杯变得无比沉重。

「这座城市又平稳地运行了一天。只是有些人，被平稳地运行过去了。」

政务内网入侵成功后第三章还没触发？

保险箱密码哪里找？

红星路 / 北纬坐标搜不到？

怎么确认有两个北辰？
在语音助手·星灵中，比对《B_契约.mp4》音轨 vs 北辰频道语音样本，结论「不一致」。
天象观测站怎么进去？
必须先读完暗涌论坛 D_张 的私信（第二章完成后）。之后打开星途地图，点击「天象观测站（市郊）」标记，详情中出现「进入观测站」按钮；也可以直接搜索「天象观测站」进入。没读私信时搜索只会返回废弃观测站的公开信息。
观测站是必做的吗？
必做。v3.6.0 起观测站已并入主线：它是政务内网解密（密钥 0412）的前置，也是第三章触发的必要条件。三份证据还会让结局叙述更完整。
李医生录音怎么解密？
用「双子星」进入母体档案库、调出复核通道后，录音以员工私钥加密。输入四位密钥 2048（即暗涌论坛邀请码），点「解密此录音」后再点磁带播放。
结局怎么触发？
第五章（真相已知后）任务目标窗口会出现红色「做出最终选择」按钮。三个选项分别对应三个结局。

08双解密环节详解

政务内网解密

在星搜中搜索「政务内网」并成功越权后，下载到的《双子计划_实施方案_2048.docx》为 AES-256 加密密文（显示为乱码）。在解密框中输入密码本密钥——即天象观测站墙上红笔圈出的四位数字 0412（老张儿子编号后四位，日记里也写明）——点「离线解密」即可解锁正文。错误会提示重试。

密钥 0412 的线索：观测站墙上星图旁红笔圈出的四位数字，也是老张日记末尾摩斯码 ----- ....- .---- ..--- 的翻译。可在政务解密页点击「播放摩斯音频」听 assets/Morse code.wav，或对照 assets/Morse Code Chart.png 翻译。

母体档案库解密

用「双子星」进入母体档案库、调出「复核申请」通道后，挂载的「李医生_自述.wav」以员工私钥加密，无法直接播放。在解密框中输入这扇地下之门的四位数字 2048（你最初进入暗涌论坛用的邀请码），点「解密此录音」；磁带卡片出现后再点磁带开始播放转写记录。
